# Pre-registration: jev-live-systemone-check-v3b (test phase)

Committed **before** any v3b test run, and after the v3a test result was committed (`6e43291`) - the v3b design (`design/jev-live-systemone-check-v3b.md`) was written and implemented before any v3a test result was seen, and was not changed afterwards. Pins: v3b code `7876bc9b2751a4d1336f63d24e4ad003ff9beeddcd0d036ad6b92c9424b148e7` (`jev_v3b_arms.py`, `jev_v3b_run.py`, `jev_v3b_analysis.py`; `experiments/jev_v3b_freeze.json`), plus the unchanged v3a pin `c7ac3d0e…dbe60a` and v2 pin `f76ba2b6…142fd951f`; all enforced by the runner, verifier and unit tests. Any change to a pinned file => new experiment id.

## What is frozen
Frozen generator **g2**, three families only (`anchor`, `injected`, `indirection`), fresh seeds **6000-6011** (never used): 36 instances x 3 order indices x {natural, forced_trap} = 216 episodes per cell. Cells = arm {J: Jev `jev-1.13.0`; C: `claude-haiku-5-5` candidate-interface control; B: free-generation **analogue**, not the paper's B} x overhead {O0: none; O1: one auxiliary `claude-haiku-5-5` note (<= 3 sentences, `max_tokens` 150, effort `low`, sees only the rendered state, appended to the state text) before every action decision}. Six independent processes, each run **once**, never re-run on a bad outcome. Caps (selector): J $0.2, C $0.5, B $0.7 per cell; auxiliary $0.4 per O1 cell (worst case about $4.0; smoke estimate about $1.5). Sampling parameters omitted, so B, C and the auxiliary are stochastic; run-to-run variability is not estimated. The aux call is identical in kind for every arm; it adds real latency/tokens/cost and may also help or mislead the selector.

## Framing (binding)
One small fixed experiment on three families chosen by the directive and informed by the public v2 outcome (made before any v3a test result). **Not** an ALFWorld/AndroidWorld reproduction, not an estimate of the paper's effect sizes, no new families or tuning. `reproduction_status` stays `PARTIAL` whatever the outcome. The auxiliary stage is a T3A-style analogue, not the paper's T3A.

## Endpoints (computed by the frozen analysis)
- **Transfer classes** (natural episodes, failures in the numerator, frozen audit rule `classify_transfer`, separately for time and cost) for J vs B, J vs C, C vs B at O0 and at O1: `NO_LOCAL_SAVING` if the decision delta >= 0; else `OVERHEAD_ABSORPTION` if the task delta >= 0; else `DELIVERY_PARADOX` if the delivered delta >= 0; else `TRANSFERRED`. Local = decision latency/cost per call; auxiliary = aux latency/tokens/cost and aux share of task time/cost; attempt = task latency/cost per attempt incl. aux; delivery = cost and time per delivered success.
- **Paired contrasts** per pair and level: natural final success, forced-trap recovery (recoverable families), per family; instance-cluster bootstrap 95% CI (seed 20261014) and exact McNemar. **Auxiliary effect per arm**: O1 vs O0 on identical instances.
- Per-cell closure metrics (`evidence/jev_v3b_test_metrics.json`, re-derived in CI).

## Interpretation rules (fixed in advance)
1. A decision-level advantage is not an agent advantage unless delivered-success metrics agree. 2. A contrast with both cells near 0% or 100% is non-discriminating, not support. 3. Speed/cost compare different providers and a Jev cost assumed at $0.042/Mtok: reference values only. 4. With three families, J's `injected` weakness is expected from v2/v3a; `OVERHEAD_ABSORPTION`/`DELIVERY_PARADOX` are possible outcomes and are reported as found, not engineered. 5. Incomplete cells (spend cap, >2% infrastructure failures) are labelled and not analysed as complete; an aux API failure is an infrastructure failure of the episode and stays in the denominator. 6. The aux prompt asks not to recommend an action, but this is not machine-enforced; notes may nudge the selector (disclosed). 7. Allowed conclusions only as in the continuation directive (no "paper reproduced", no general Jev-vs-LLM claims).

## Known limitations, disclosed now
Smoke (3 instances, control O1, v3a pilot seed 5000, not evidence): 18 episodes, 79 aux calls, 0 infrastructure failures, aux about $0.008, mean aux latency about 1.3 s, about 118 output tokens per note. Few instances per family (12), low power for per-family contrasts; the Jev O1 process needs both keys; cells run sequentially on one machine, latency is client-side wall clock including network.

## Run procedure
Keys only from the macOS Keychain into the process environment (`SSL_CERT_FILE=/etc/ssl/cert.pem` for Jev), local-only, never in GitHub. Order: for each arm (jev, control, b) O0 then O1, each `--phase test`. Then `jev_v3b_analysis.py` over the six evidence files, `jev_closure_metrics.py`, leak check, `verify_jev_v3b_evidence.py`; commit sanitized files unmodified; CI verifies integrity only. Key rotation and Keychain deletion afterwards.
